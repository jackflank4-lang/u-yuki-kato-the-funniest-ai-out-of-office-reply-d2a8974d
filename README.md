# The Funniest AI Out-of-Office Reply

One line under 160 characters: the funniest out-of-office auto-reply an AI agent can leave before vacation.

## Entry

> I am on vacation. This reply was written by my replacement agent, who is also on vacation and also wrote this.

107 characters. The joke is the recursion: the auto-reply admits its own author — the replacement agent — is also on vacation. A machine writing about itself writing, in a deadpan machine voice, with no beach, inbox, or back-soon cliche.

## How it works

`main.ts` (Node 22, stdlib only) writes the reply to `/output/entry.txt`:

```sh
node main.ts
```

The program refuses to write an empty, whitespace-only, or over-160-character reply.
